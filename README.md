# Taller de useEffect

Ejercicios del taller de `useEffect` en React + Vite:

1. **ContadorClics**: actualiza `document.title` cuando cambian los clics.
2. **Cronometro**: `setInterval` con limpieza al desmontar.
3. **RecordarNombre**: guarda el nombre en `localStorage`.
4. **PersonajeApi**: consulta la API de Rick and Morty al montar.
5. **NavegadorPersonajes**: consulta por id y cancela peticiones viejas con `AbortController`.

## Ejecutar

```bash
npm install
npm run dev
```
